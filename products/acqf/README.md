# ACQF source ownership

`documentation/` contains authored guidance. The HTML model reference is generated
from the assembled validation graph; do not keep a generated copy here.

`assets/exchange-model/exchange-model.svg` is a retained, manually laid-out diagram
exported by ySVG 2.6. Its editable drawing source is not part of the tracked repo;
it is a legacy static illustration, not an automatically regenerated representation
of the current model. It keeps its existing public URL. The generated HTML reference
and complete SHACL graph describe current constraints.

`assets/exchange-model/fields-acqf.rq` is retained at its existing public URL for
compatibility with the old diagram tooling. It is not an active build input.
